# Robotic Hand — CAD Models

This repository contains the CAD models and mechanical designs for my ongoing robotic hand project. The project explores tendon-driven actuation, multi-degree-of-freedom finger mechanisms, and modular designs for robotic dexterity.

## Design Overview

The robotic hand uses tendon-driven mechanisms to produce finger movements. Servo motors apply tension to tendons, allowing the fingers to move without requiring a separate actuator at every joint.

The design for the index finger provides 3 actuatable inputs, adduction/abduction, MCP flexion and a combined PIP-DIP flexion. 

The design process focuses on:

- **Tendon-driven actuation:** Using tendons to control finger movement.
- **Multi-degree-of-freedom motion:** Exploring finger curling and side-to-side movement.
- **Modular construction:** Designing finger mechanisms that can be developed, tested, and modified independently.
- **Mechanical refinement:** Iterating on geometry, range of motion, tendon routing, and component placement.
- **Sensor integration:** Exploring how compact tactile sensors could fit within the robotic fingertips.

## Repository Contents

This repository contains the CAD files associated with the robotic hand's mechanical development.

Models include individual finger components and other mechanical parts used to prototype the hand.

The design is a work in progress, and files may represent different stages of development rather than a single finalized assembly.

## Design Tools

- **Fusion 360** — Primary mechanical CAD design and assembly.

All provided files use the .stl format

## Development Goals

- Improve finger range of motion and mechanical reliability.
- Refine tendon routing and actuator placement.
- Develop compact, modular finger mechanisms.
- Explore alternative finger and thumb configurations.
- Make room for tactile sensing hardware within the fingertip.
- Iterate on designs based on physical prototyping and control testing.

## Project Status

The hand currently has a tendon driven index finger with a prototyped thumb. Work is being done to improve the thumb design and fix PIP-DIP motion in the index finger.

These designs are actively evolving alongside the broader robotic hand project. Not all models are finalized or validated through physical testing, and individual parts may require further refinement before fabrication.
